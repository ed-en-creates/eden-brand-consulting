# Eden Brand Consulting

A premium, interactive brand consulting website built with a modern tech stack. Features interactive 3D surfaces, sleek animations, and a dynamic dark/light mode experience.

## ✨ Features

- **Interactive 3D Backgrounds**: Custom-built `DottedSurface` component using React Three Fiber.
- **Dynamic Design System**: Custom-tailored dark and light modes with seamless transitions.
- **Modern UI Components**: Powered by Radix UI and Framer Motion for high-quality interactions.
- **Seamless Animations**: Smooth scroll and hover effects for a premium feel.
- **AI-Driven Infrastructure**: Integrated AI Lab and intelligent processing features (WIP).

## 🚀 Tech Stack

- **Frontend**: [React 19](https://react.dev/), [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/), [Lucide React](https://lucide.dev/)
- **3D Graphics**: [Three.js](https://threejs.org/), [@react-three/fiber](https://github.com/pmndrs/react-three-fiber)
- **Backend**: [Express](https://expressjs.com/)
- **Deployment**: [Vercel](https://vercel.com/)

## 🛠️ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+)
- [pnpm](https://pnpm.io/) (Recommended)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ed-en-creates/eden-brand-consulting.git
   cd eden-brand-consulting
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

## 📦 Deployment

The project is optimized for deployment on **Vercel**. Connect your GitHub repository to Vercel for automatic deployments on every push to the `main` branch.
